# Windows icon artwork

The game and configuration artwork was edited with the built-in ImageGen tool from the user-supplied Snake portrait (clipboard reference ee572e69-bb99-4999-95b6-f18fb502b403, 12 October 2026).

Art direction: retain the actual game portrait and red circular border, add a black VR headset and visible straps, remove the duplicated lettering, keep exactly one VR with a red V and contrasting ivory R. The configuration variant adds an ivory gear badge to the same artwork. Pixels outside the circle are transparent.

Source assets: `docs/images/mgs5vr-game.png` and `docs/images/mgs5vr-config.png`. Windows resources: `tools/icons/mgs5vr-game.ico` and `tools/icons/mgs5vr-config.ico`, containing 16, 24, 32, 48, 64, 128 and 256 pixel images. ICO packaging/resampling used Pillow; the portrait/headset artwork was generated by ImageGen.
