# MGS5VR Experimental — September 20, 2026

This packages the v12 gameplay DLL with the Steam startup correction. The user
reported the candidate good to go and approved packaging after headset testing.
It is an experimental release; complete mission, weapon and runtime coverage
has not been established.

## Install or update

1. Close MGSV and extract the entire release folder.
2. Open **MGS5VR-Launcher.exe**, select your owned `mgsvtpp.exe`, and choose
   **Install VR** or **Update / Keep My Settings** for an existing installation.
3. Connect PC VR, leave Steam running and signed in, then choose **Launch**.
   **Launch-Headset.cmd** also uses the saved game selection.

The launcher supplies Steam's app identity and selects the physical OpenXR
runtime for the game process. Personal controls/settings are preserved during
updates. Game assets are imported locally; game files and saves are not bundled.
An existing third-party `dinput8.dll` remains a loader conflict requiring resolution.

## Changes included

- Original iDroid mappings: tap left Menu to open, hold left Menu for Pause,
  right B to back out. Holding B for 750 ms can escape the forced FOB tutorial
  lock. Dismiss **Exit Tutorial** with A; if the device remains out, tap left
  Menu to stow before reopening. Tutorial completion flags are not changed.
- Camera continuity through brief player/controller publication gaps, native
  head-animation stabilization, and retained support-hand contact.
- Forearm status, wrist equipment menus, the game's four-category trigger
  preview, palm-aligned iDroid projection, and native UI canvas bounds.
- Both binocular eyes, peripheral world camera/LOD handling, and optic fitting
  corrections. Snap turning is opt-in; new default controls use native smooth turn.
- Cabin input isolation, Continue/loading handoff changes, visible controls
  editing, and configuration bounds up to 8192 per render dimension.
- Direct headset launch now supplies the Steam identity that was missing when
  Explorer launches failed with **Unable to initialize SteamAPI**.

The downloadable candidate keeps `opening.interactive_cabin=1`, as tested.
The source INI retains its opt-in default; the package manifest records this
override. Existing installations keep their selected opening mode on update.
Native animal availability depends on game state and owned local assets; Quiet
and two pickup rats are not advertised as completed features.

## Validation and limits

The candidate passed the 16 local automated suites, assembled installer/update/
rollback fixtures, and bounded SIM checks covering Continue, iDroid recovery,
map pan/zoom, tabs, submenus, close and reopen. Steam startup reached native
frames on Oculus / Meta Quest 3. The user's subsequent approval is recorded
separately from these automated and SIM results.

Remaining work includes Pause arm tracking and menu fit; complete wrist routing
for notifications/captions; long-session body/horse drift; complete turret,
vehicle, weapon and item coverage; and affected-runtime blackout testing.
Resolution above 4K and Linux/Proton headset performance are not certified.
Ground Zeroes remains incomplete. General third-party mod compatibility,
including Infinite Heaven/IHHook coexistence, is not established.

## Community fork and supplied-file status

Thanks to Coco, Silent, Vinion and the other community testers for reports and
source experiments. Reviewed material is not automatically included code:

- **Silent (`s-ilent`)**: adaptive pacing and async mailbox work were reviewed;
  neither is merged here. The final worker revision removes immediate-context
  synchronization and needs a separate native D3D11 integration and performance test.
- **Vinion (`vinionsinho`)**: the movement-stabilization fork was reviewed;
  its separate configurable filter is not merged. This candidate has its own
  root-relative stabilization and stance-following behavior.
- **Supplied `controller_rig (1).cpp` and `head_camera (2).cpp`**: received and
  compared. Related stabilization and rig changes are present, but these files
  were not imported wholesale. Their hook fallback and differing filter behavior
  remain separate review items; replacing the current files would omit newer work.
